# 🧼 Clear BG — Instantly Remove Image Backgrounds

✨ Instantly remove backgrounds from any image with **Clear BG**! Upload your photo, erase the unwanted background with AI, and download the clean, transparent result — all in seconds.

---

## 🚀 Features

- 📷 Upload images or paste a URL
- ⚡ One-click background removal using Rembg
- 🖼️ Download high-quality, transparent images
- 🎯 Clean UI powered by Streamlit

---

## 🛠️ Tech Stack

- 🐍 Python
- 🎈 Streamlit
- 🤖 rembg
- 🧠 onnxruntime, numpy, Pillow

---

## 📦 Installation

Clone this repo and install dependencies:

```bash
git clone https://github.com/yourusername/clear-bg.git
cd clear-bg
pip install -r requirements.txt
````

---

## ▶️ Run the App

```bash
streamlit run app.py
```

# 🧼 Limpar BG

Limpe suas imagens em segundos com o **Clear BG**! Remoção de fundo fácil, sem necessidade de habilidades de design, com resultados de alta qualidade sempre.

![LimparBG](https://github.com/KrishBharadwaj5678/ClearBG/blob/main/ClearBGDemo.png)

## 🚀 Funcionalidades

| Funcionalidade                     | Descrição                                                   |
| ---------------------------------- | ----------------------------------------------------------- |
| 📷 **Upload / URL**                | Envie imagens do seu dispositivo ou cole uma URL de imagem. |
| ⚡ **Remoção com um clique**        | Remova o fundo da imagem instantaneamente usando o rembg.   |
| 🖼️ **Download em alta qualidade** | Baixe a imagem resultante com fundo transparente.           |
| 🎯 **Interface simples**           | Interface intuitiva e limpa construída com Streamlit.       |

## 🛠️ Tecnologias

| Tecnologia          | Finalidade                                        |
| ------------------- | ------------------------------------------------- |
| 🐍 **Pitão**       | Linguagem principal do projeto                    |
| 🎈 **Streamlit**    | Criação da interface web interativa               |
| 🤖 **rembg**        | Remoção de fundo de imagens                       |
| 🧠 **onnxRuntime** | Execução eficiente de modelos de machine learning |
| 🔢 **NumPy**        | Processamento numérico e de arrays                |
| 🖼️ **Travesseiro**      | Manipulação de imagens                            |

# 🧼 Clear BG

Очистите изображения за считанные секунды с помощью **Clear BG**! Простое удаление фона без навыков дизайна и с высоким качеством результата.

![ClearBG](https://github.com/KrishBharadwaj5678/ClearBG/blob/main/ClearBGDemo.png)

## 🚀 Возможности

| Функция                              | Описание                                                            |
| ------------------------------------ | ------------------------------------------------------------------- |
| 📷 **Загрузка / URL**                | Загрузка изображений с устройства или вставка ссылки на изображение |
| ⚡ **Удаление в один клик**           | Мгновенное удаление фона с помощью rembg                            |
| 🖼️ **Скачивание высокого качества** | Скачивание изображения с прозрачным фоном                           |
| 🎯 **Простой интерфейс**             | Удобный и интуитивный интерфейс на базе Streamlit                   |

---

## 🛠️ Технологии

| Технология          | Назначение                                    |
| ------------------- | --------------------------------------------- |
| 🐍 **Питон**       | Основной язык разработки                      |
| 🎈 **Стримлит**    | Создание интерактивного веб-интерфейса        |
| 🤖 **Рембг**        | Удаление фона изображений                     |
| 🧠 **ОннексРантайм** | Эффективный запуск моделей машинного обучения |
| 🔢 **НамПай**        | Обработка числовых данных и массивов          |
| 🖼️ **Подушка**      | Обработка изображений                         |

# 🧼 クリアBG

画像を数秒で簡単にクリーンアップできる **Clear BG**！デザインスキル不要で、ワンクリックで高品質な背景削除ができます。

![クリアBG](https://github.com/KrishBharadwaj5678/ClearBG/blob/main/ClearBGDemo.png)

## 🚀 機能

| 機能                    | 説明                              |
| --------------------- | ------------------------------- |
| 📷 **アップロード / URL入力** | デバイスから画像をアップロード、または画像URLを貼り付け可能 |
| ⚡ **ワンクリック背景削除**      | rembg を使用して即座に背景を削除             |
| 🖼️ **高品質ダウンロード**     | 背景透過の画像をそのままダウンロード可能            |
| 🎯 **シンプルなUI**        | Streamlit による直感的で使いやすいインターフェース  |

## 📦 インストール方法

### 1️⃣ リポジトリをクローン

```bash id="4m8q2p"
git clone https://github.com/KrishBharadwaj5678/ClearBG.git
```

### 2️⃣ プロジェクトフォルダへ移動

```bash id="9k3w0t"
cd ClearBG
```

### 3️⃣ 依存関係をインストール

```bash id="x1v7lm"
pip install -r requirements.txt
```

### 4️⃣ アプリを起動

```bash id="c8p2ad"
streamlit run app.py
```
